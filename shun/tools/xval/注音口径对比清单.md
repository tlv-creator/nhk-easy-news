# 6 集 ruby 逐字化：逐条对比清单

> 目的：peer 问「会社 那种逐字化对 6 集是否更好」⇒ 这份清单给出**逐条**证据，供他逐条核。
> 结论先行：**是，逐字更好**（用户的硬要求是「读音必须逐字 ruby，不是整块注音；不规则词整块兜底」）。

## 0. 口径（两个版本都遵守）

```
① 纯汉字词：每个汉字一个 ruby 单元（逐字）
② 读音 = 词级读音（标准词读音，来自已发布 ruby 反推的 213 条词表 + IPADIC）
③ 逐字切分 = 候选并集 DP（kanjidic2 全部读音 ∪ 熟字訓表 ∪ 已发布数据挖到的实际读音）
④ 切不出 ⇒ 整块兜底（真·熟字训：今日/きょう、旅行/りょこう ⇒ **本来就该整块**）
```

## 1. 最重要的验证：读音内容**一个音都没改**

```
6 集 390 句：读音流与线上现成版一致 390 句 / 不一致 0 句（0.0%）
⇒ **差异只有「粒度」，没有「读音」** ⇒ 这是纯粒度细化，不是改读音
```

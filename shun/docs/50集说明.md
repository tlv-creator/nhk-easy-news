MiniMax Token Plan 额度已耗尽（`status_code 2056`），**本次没有再调用 MiniMax 任何接口**。
新增的 31 集全部由**已经付费换来的存量资产** + **平台侧通道** + **本地规则引擎** 拼出来：

```
① 转写 + 中文翻译 + 四类括号结构
   → 平台通道 connector__matrix__audios_understand
   → 走平台侧，**不烧订阅额度**；31 集 × 一次最多 10 个 entry，实测每批 5 集约 60 秒
② 逐字 ruby 注音
   → shun/tools/ruby.py（上下文读音表 + kanjidic2 DP；词表命中 ⇒ 整块一个单元）
③ 句级时间轴
   → 交接包里的 44 集词级 ASR（asr/<uid>.json，segments[].words[] 带 s/e）
   → 字符级对齐把平台句映射回词级时间戳
④ 第二层（块内骨架 inner / 词级拆解 parts / 主句骨架 skel）
   → 规则引擎（shun/tools/xval/analyze.py + frame.py）
   → 🔴 **frame 一个字节不动**（平台的语义分组已经过闸门）
```

### 关键工程决策（踩过的坑）

| 坑 | 现象 | 修法 |
|---|---|---|
| 平台切句比 ASR 细 | ep243：平台 63 句 vs ASR 52 句 | **字符级对齐**，不是整句相似度（整句 ratio 会被长句稀释，明明包含却判成不匹配） |
| ASR 与平台文本差异大 | 时间轴全挤在开头 30 秒 | 改用 **cues 做桥**：平台句 ↔ cue 句 ↔ 词级 ASR |
| 平台输出**半开口括号** | ep107 丢 18 个块（「［旅行を」+「始める］」） | 剥括号认三种形态；**s 里的括号比 b 字段权威** |
| 平台给日文**加字间空格** | ep304 整集「私 も フリーランス に」 | 删「日文/假名/标点之间」的空格，保留 ASCII 词之间的 |
| 平台 b 值带「方」字 | `b='〈方〉'` | 归一化到线上四类 `〈〉` |

## 2026-10-25 更新（本轮修复）

### ① 注音：11 处「汉字没读音」+ 1 处「错读音」全修
```
症状：ep140「…何をするか聞きました」→ 聞(空)     ← 汉字上方完全没有假名
      ep304「…と言う言葉を聞きます」→ 言(い)·葉(は)  ← 错读（ことば ≠ いは）
根因：ruby.py 的 fix_okurigana 后处理
      「若某段读音末假名 == 下一段表层首假名且下一段读音为空 → 去掉该末假名」
      ⇒ 把**汉字自己的读音**（聞→き）误当成「送り假名重复」删掉了
修法：① 只有「删完会变成空串」时才不删（保护 聞→き 这种唯一读音）
      ② DP 无解 ⇒ **整块 emit 一个单元**（用词级读音），不再逐字硬凑
          ⇒ 言葉 ⇒ 言葉(ことば)
验证：全量 3618 句重算，含汉字单元 11843，空读音 **0** ✅
      已发布 13 集逐句比对：改数据时 3607/3618 句**一个字节未动**（只修缺陷句）
```

## 2026-10-25 第四轮：注音粒度细化（逐字优先）+ 三处引擎 bug 修复

### ① 粒度改版：整块 1805 → 583（15.0% → 4.4%）
```
问题：用户硬要求是「读音必须**逐字 ruby**，不是整块注音」
     但线上 50 集里 15.0% 的汉字单元是「多字整块」（如 教師/きょうし 挂两个字上）
原因：ruby.py 的规则①是「**词表命中 ⇒ 直接整块**」
     ⇒ 把 144 个**本来能逐字**的词也整块了（教師→教(きょう)・師(し) 就能切）
     ⇒ 违反用户硬要求。

修法（关键：只重新分配旧读音，**不重选读音**）：
  新增 `shun/tools/refine_granularity.py`
  · 输入旧 ru（表层 + 读音），输出更细的 ru
  · 候选集**只用已发布数据里该字实际用过的读音**（published_reading.json）
  · 硬保证：① 表层拼接逐字不变 ② 读音流逐字符不变
  ⇒ 读音内容零变化，只有「读音挂在几个字上」变了

🔴 为什么不用 ruby.py 重算（这版踩的坑，重要）：
  ruby.py 的 DP 会**重新选择**每个字的读音（音读 vs 训读）
  ⇒ 已发布数据里读对的字被改坏：
       風(かぜ) → 風(ふう)   ❌（かぜ 是训读，ふう 是音读）
       腹(はら) → 腹(なか)   ❌
       停(てい) → 停(ばすてい) ❌（「バス」被当送り假名剥掉）
  ⇒ 教训：**粒度变换与读音选择必须分开** ⇒ 粒度用 refine_granularity，读音用已发布事实
```

### ② ruby.py 三个真 bug（都修了）
```
① **DP 不要求用尽读音** ⇒ 读音尾部被静默丢弃
   症状：試合/しあい 被切成 試(し)・合(あ) ⇒ 读音流变成「しあ」（丢了 い）
   修法：必须 j == len(reading)（读音流逐字用尽），否则返回 None 交整块兜底
② **叠字符「々」被当送り假名** ⇒ 「色」独吞整个读音
   症状：色々 产出 色(いろいろ)・々(空) ⇒ **多注了一个音**
   修法：々 是表意文字（U+3005）⇒ 单独识别，**整块 emit**
   （々 的读音常音变：時々=ときどき、人々=ひとびと ⇒ 机械复制前字读音也是错的）
③ **片假名（外来语）被当送り假名剥掉**
   症状：バス停 产出 バス・停(ばすてい) ⇒ 读音挂在错的字上
   修法：split_surface 的边界只认**平假名**（送り假名）与**汉字/叠字符**
```

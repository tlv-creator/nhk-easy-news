# tadoku/books56c —— 批次 1（官方朗読 Level 0，12 本）

本目录是**批次 1** 的书数据：**12 本 Level 0**（ISBN 卷 `9784872177497` / `9784866398310`，各 6 本）。
Start（超入門）8 本与 Level 2 的 9 本**不在本批**（见文末「为什么不全交」）。

## 目录结构

```
tadoku/books56c/
  books/<tag>.json      ← 书数据（App 数据格式，s/e 暂为 0，时间轴待算）
  manifest.json         ← 每本的 tag/官方标题/句数/音频轨/时长/book_id
  asr_truth/            ← 官方朗読 ASR 真值（20 轨，由同伴提供）
```

## books/<tag>.json 的格式

与 `tadoku/books56/out/*.json` 同款，同伴的 `tools/align_audio.py` 直接吃：

```json
{"ep": null, "tag": "level0-kaze-to-taiyou", "title": "風と太陽",
 "desc": "The Wind and the Sun", "level": "Level0", "dur": 236.8,
 "audio": "9784872177497/Track01.mp3",
 "cues": [{"s": 0.0, "e": 0.0, "rows": [{"t": "…", "ru": [["風","かぜ"], …],
                                          "zh": "…", "w": [...], "blk": [...], "g": {...}}]}]}
```

- `s` / `e` 一律 **0** ⇒ 时间轴由 `align_audio.py` + `rebuild_data.py` 计算（对方负责）。
- `ru[i] = [表层, 读音]`，**表层拼起来必须等于 `t`**（构建时已断言，违例 0）。
- `zh` 为简体中文，与 `t` **逐句 1:1**。

## 文本来源与可信度

| 环节 | 来源 | 性质 |
|---|---|---|
| 日文正文 | B站「日语空空老师」绘本**跨页扫描视频** ⇒ 视觉通道 OCR | 印刷原文（权威） |
| 逐字注音 | 同上（画面上是**印刷的假名注音**） | 印刷注音（权威） |
| 简体中文 | UP 叠在书页上的蓝字初稿 → subagent 重译 | 人工级 |
| 轨↔书对应 | 官方朗読 ASR × 印刷原文，双向字符流覆盖率 **0.59~0.90** | 内容级确认（非顺序假设） |

⇒ **印刷原文与官方朗読是两个互相独立的源**，且互相覆盖 ⇒ 轨↔书对应不靠顺序假设。

## 已知的三类缺陷与裁决

完整清单见 `tadoku/batch1_decisions.json`（逐条带证据）。摘要：

1. **OCR 错字**：《助けて！》句32 印的是 `良〈りょう〉`，OCR 给了 `長〈よし〉`
   ⇒ 用 kanjidic2 独立校验（单字冲突 23 处 ⇒ 人工裁决后只此 1 处是真错字）。
2. **注音归属错**：`バス停〈ばすてい〉`（ruby 跨两词）、`天〈あま〉の川〈がわ〉`（助词读音并进「川」）⇒ 已按同书其它处改正。
3. **书末简介块**：每本最后都有「标题页 + 官方あらすじ + NPO 介绍」⇒ 按**精确行内容**删除
   （⚠️ 不能按行号：去重后行号会错位）。

**特意保留**：《ウサギとカメ》最后两页是**唱歌页**（含乐谱与 1~4 段唱词）⇒ 是书的正文。
只是官方朗読不唱它 ⇒ 那 22 行会成为哑句，这是如实反映。

## 为什么不全交（Start 8 本 / Level 2 9 本）

- **Start（超入門）8 本**：**没有印刷全文源**——出版社样章页只给每个故事开头 1~2 页；
  B站没有这一级；GitHub 镜像没有。手上只有官方朗読 ASR（口语写法）。
  ⇒ 下一轮做「样章页开头 + ASR 补全篇 + 自算注音 + 逐句人工校对」，并标 `text_source: "sample_pages+asr"`，
  **不拿 ASR 的口语写法冒充印刷原文**。
- **Level 2 的 9 本**：样章页覆盖不全（卷 `9784872176254` 实测 **0 张**样章图）⇒ 同样缺印刷全文源。

## 重建指引（对方）

```
1) 轨↔书：按 manifest 的 audio_mp3 逐轨对应；用字符流覆盖做一次校验（本次已确认）
2) align_audio.py：s/e = 0 的 cues → 用 asr_truth/<isbn>-trackNN.json 算时间轴
   🔴 三关：文本能对上 / 顺序能对上 / 单调不重叠（align_audio.py 已是唯一权威实现，别写第二套）
3) rebuild_data.py：哑句归零（no_audio 的 s/e 一律 0）
4) 验收：命中行时间窗 + 端到端 ASR 带反向对照
```

## 三、🔴 本轮修掉的一个真 bug（端到端逮到）

**现象**：`level4-takashi-nagai…`（永井隆）末句 `s=1220.0 / e=1220.1` ⇒ 时间窗只有 **0.1 秒**
⇒ 端到端切片太短 ⇒ 抽验假失败（cov 0.17）。

**根因**（`align_audio.py` 末行结束时间的估算）：

```python
est = max(b_start[-1] + 1.0, est)      # 旧顺序：先兜最小窗
se  = SPEECH_END[tag]
if se: est = min(est, se)              # ① 再用实测 speech_end 夹取
```

实测 `speech_end = 1219.61s`，而 **ASR 末行起点 = 1220.0s** ⇒ 实测值比起点**还早 0.4 秒**
（平台时间戳与能量分析有 ±0.5~1 秒噪声）⇒ `min()` 把结束时间夹到起点**之前** ⇒ 窗被压成 0.1 秒。

**修法**（两条一起）：

```python
est = b_start[-1] + (b_len[-1] / max(0.5, rate))
se  = SPEECH_END[tag]
if se and se > b_start[-1] + 0.2:      # ② 实测值与 ASR 起点矛盾 ⇒ 信 ASR，不夹
    est = min(est, se)
est = max(b_start[-1] + 1.0, est)      # ① 最小窗挪到夹取**之后**
```

**效果**：永井隆末句 `e` 1220.1 → **1227.85**（40 字长句的正常时长）；其余 6 本**零变化**。
**回归**：旧 34 本（2443 句 / 哑句 245 / 乱序 9）与批次 1（445 句 / 哑句 77 / 乱序 1）
与修前基线**逐项一致、零变化**（这两个集合没有实测 speech_end，且不落在矛盾区间）。

🔴 **通则**：「实测值当硬上限」的前提是**实测值本身可信**；当两个独立测量源矛盾时，
**要判哪一个在这条链路上更可信**（ASR 行起点是逐行对齐出来的，能量分析只有 ±0.5~1 秒），
而不是无脑取 min。

## 五、哑句分因（「哑句」≠「缺陷」）

以永井隆的 40 句为例（分类器口径：整条 ASR 流里**根本没有** ⇒ 印刷专有）：

- **A 类 24 句** = **照片说明 / 图注**（「11時2分で止まった時計」「父と母と隆」「焼け野原になった長崎の町」「壊れて焼けた浦上天主堂」…）
  ⇒ 朗読只念正文叙述，**不念图注** ⇒ 标哑句是**如实反映**
- **B 类 14 句** = **年表条目**（「1928長崎医科大学に入る」「1940大学の助教授になる」…）
  ⇒ 朗読念的是「1928年、長崎医科大学に入る」（多一个「年」）⇒ 字符流对不上 ⇒ 哑句
- 另有书末的**解说页**（3 句）：教材用**汉字数字**（「一九四五年、八月六日」）、朗読用**阿拉伯数字**（「1945年8月6日」）
  ⇒ 写法不同 ⇒ 印刷把同一段内容用另一种写法重复了一遍 ⇒ 朗読不念 ⇒ 哑句

⇒ **这 40 句全是印刷专有元素（照片说明 / 年表 / 解说页），不是对齐缺陷。**

## 六、端到端抽验（切音频 → ASR → 比文字）

- 覆盖率阈值 **0.6**（0.5 对短句会假阳）
- 反向对照：故意往后错 30 秒切 ⇒ 应当**不**命中（证明判据不是恒绿）
- 反向样本取「在 ASR 真值里只出现一次」的句子（避免回环结构让判据失效）

**结果**：正向全命中，反向全不命中 ⇒ 详见 `e2e_result.json`。

## 七、与线上数据的关系

- `out/<tag>.json` 与线上 `data/eps/<tag>.json` **顶层键 / cue 键 / row 键完全一致**（含 `st/w/blk/g`）

# 第 1 批官方朗読（20 本）· 对齐结果

生成方：主会话（对齐 + 验收）｜数据源：官方朗読（storage.ask-books.com 官方 zip）

## 目录
- `out/<tag>.json` —— **最终交付数据**（与线上 `data/eps/*.json` 同格式）
  · `cues[i].s/e` = 音频里的真实时间（秒）
  · `cues[i].no_audio` = 1 ⇒ 这句在音频里没有对应（**只在哑句上出现**）
- `asr_truth/<tag>.json` —— ASR 真值（0 额度平台通道，40 秒切段，段内时间戳 + 已知起点）
  · `[{start, text}]`，start = 书内绝对秒

## 怎么用（构建会话）
1. 把 `out/<tag>.json` 的 `cues[i].s/e` 与 `no_audio` 写回 `work/media/<slug>.json` 真源
2. 重建 → 不变量检查（严格递增 / 不重叠 / e>s）
3. **句序一一对应已核对**：out 的 cue 数 == manifest 的 sentences == 你 books 文件的 cue 数

## 验收（独立回验：切音频 → ASR → 比字幕文字）
- 新时间轴：**59/60 句对得上**（切出来的那段音频，转写出来就是这句字幕）
- 旧时间轴（你给的估算）：**1/58** ⇒ 旧时间轴基本不可用

## 两件你可能还不知道的事（都已在数据里体现）
1. **平台时间戳有两种格式**：`【0】` 和 `【0秒】` ⇒ 旧解析器只认前一种，
   **已发布版本因此静默丢了 12% 的 ASR 真值**（旧 34 本哑句 484 → 修复后 251）
2. **别册非虚构类书的 OCR 把振假名并进了正文**（`これは、むかし昔`）⇒ 覆盖率被拖低
   ⇒ 对齐改用**双通道**（整句 + 汉字骨架，取高者）；**你的正文没被我改动**，
   但显示上仍然是「むかし昔」这种重复 ⇒ 要修显示得在你那边改

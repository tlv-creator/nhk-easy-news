## 输出

### ② 新字段（下一版「语法讲解」面板用）

`work/syn_out/<epid>_<track>.json` 里再加一个 `"blk"` 字段：

```json
{
  "blk": {
    "0": {
      "frame": "[皆さん] ［同僚との関係は］ （どうですかね）",
      "frameLabels": ["呼语", "主题", "谓语（疑问＋确认）"],
      "skeleton": "主句骨架：［〜は］＋（どうですかね）＝\"〜怎么样呢\"。",
      "blocks": [
        {"range": [0, 3], "text": "皆さん",
         "parts": [["皆さん", "呼语"]],
         "notes": ["[皆さん]：呼语，\"大家\"。", "独立成分，用来呼唤听者。"],
         "zh": "大家"},
        {"range": [4, 7], "text": "同僚との関係は",
         "parts": [["同僚", "名词"], ["との", "助词"], ["関係", "名词"], ["は", "主题助词"]],
         "notes": ["同僚：名词，\"同事\"。",
                   "との：格助词「と」＋「の」，\"与……的\"。",
                   "関係：名词，\"关系\"。",
                   "は：主题助词，把「同僚との関係」提为主题。"],
         "zh": "与同事的关系"}
      ],
      "zh": "大家，和同事的关系怎么样呢？"
    }
  }
}
```

**字段说明**

| 字段 | 含义 | 硬约束 |
|---|---|---|
| `frame` | 整句的层次结构 | 用**四类括号**标出四种语法层级；每个片段**逐字来自原句** |
| `frameLabels` | 每层下面的语法角色标注 | 与 `frame` 的层一一对应 |
| `skeleton` | 主句骨架 | 只有**两层以上修饰**的句子才写；单层句**不要凑** |
| `blocks` | 逐块拆解 | 顺序 = 原文顺序；每块 `range` = `[起始字符, 长度]` |
| `blocks[].parts` | 块内成分分解 | `[[片段, 词性/语法角色], …]`，用 `＋` 连起来读 |
| `blocks[].notes` | 2~4 条说明 | 讲清「这个成分是什么 + 起什么作用」；**要落到形态链条** |
| `blocks[].zh` | 该块的中文意思 | |
| `zh` | **整句**中文（完整翻译，不是摘要） | |

**四类括号 = 四种语法层级（全局一致）**

```
[ ]   连接词 / 独立成分（呼语、承接词、转折词）
［ ］  从句（条件、让步、修饰、宾语从句…）
〈 〉  句体成分（主语、宾语、补语等句内成分）
（ ）  谓语（动词/形容词 + 助动词，含疑问与终助词）
```

**完整样例（照这个格式与详略程度做，不要自行发挥）**

```
一、大框架

[皆さん] ［同僚との関係は］ （どうですかね）
  呼语         主题              谓语（疑问＋确认）

主句骨架：［〜は］＋（どうですかね）＝"〜怎么样呢"。

二、逐块拆解

第一块：皆さん
- [皆さん]：呼语，"大家"。
- 独立成分，用来呼唤听者。

第二块：同僚との関係は

同僚 ＋ との ＋ 関係 ＋ は
名词   助词    名词   主题助词

- 同僚：名词，"同事"。
- との：**格助词「と」＋「の」**，"与……的"。
  - と：表示对象。
  - の：连体修饰。
- 関係：名词，"关系"。
- は：**主题助词**，把「同僚との関係」提为主题。

意思：**"与同事的关系"**。

第三块：どうですかね

[どう] ＋ です ＋ か ＋ ね
 疑问词   断定礼貌体 疑问  终助词

- [どう]：疑问副词，"怎么样"。
- です：**断定助动词**礼貌体。
- か：**疑问终助词**。
- ね：**终助词**，表确认/共鸣。
- 合起来：**"怎么样呢"**。

整句意思：**"大家，和同事的关系怎么样呢？"**
```

## 硬性纪律

- 🔴 **每个片段必须逐字来自原句**（不能改写、不能脑补、不能换同义说法）
  ⇒ 前端要靠它在原句里定位（可点、可注音）⇒ **`range` 必须是原句的字符位置**
- 🔴 **讲某个词时要落到形态链条**：`ある → あって → あっても`、`ある → ない → なかった → なかったら`
  —— 别只讲一个形
- 🔴 讲解用**简体**中文（界面文案沿用既有繁体/日式风格，不要混）
- 🔴 「整句意思」是**完整的中文翻译**，不是摘要
- 🔴 `notes` 每块 2~4 条；块数多时按「块」分，不要把整句塞进一块
- 🔴 **例句必须是本剧真实台词**（可以引本剧其它句子），不能造

# AGENT_TASK —— 句子翻译契约（派 subagent 干这个）

## 你要做什么

把 NHK やさしいことばニュース 的日文台词**逐句**翻成简体中文。**一行对一行，不许合并、不许拆分、不许漏句。**

## 输入

`work/asr/<epid>_<track>_cues.json`，形如：

```json
{"cues": [
  {"ja": "台風のニュースです。", "s": 0, "e": 2475},
  {"ja": "気象庁によると、大きくてとても強い台風30号が、沖縄県の近くに来ています。", "s": 2475, "e": 9067}
]}
```

- `track` = `easy`（易懂版，慢速音）或 `sp`（普通版的电视播报稿）
- `s`/`e` 是毫秒，**不用管**

## 输出

`work/zh/<epid>_<track>.json`：

```json
{
  "0": "这是台风的消息。",
  "1": "据气象厅消息，一个非常大、非常强的台风30号正在冲绳附近靠近。"
}
```

🔴 **键是句子的下标（字符串），值是这一句的中文**。
🔴 **下标必须和输入的数组顺序一一对应**；对不上号的直接算失败（不要"差不多就行"）。

## 风格（照已发布数据）

1. **口语化**、自然，像老师讲给 N5 学习者听；**不要书面腔**
2. **数字两侧留空格**：`「第 277 期」`「1番」`「800 人」`「33℃」
3. 专有名词/英文**保留原文**：`台风30号`、`NHK`、`PHP`
4. 语气词（えー、ねー）翻译成自然的中文语气即可
5. 简体中文（界面文案沿用既有风格，但**讲解内容用简体**）

## 硬性纪律

- 🔴 **不许自己编原文**。原文以输入为准。
- 🔴 **不许把两句并成一句**来"省事"——下标必须对得上。
- 🔴 遇到看不懂的句子，**照直翻**，并在文件末尾加一行注释说明；不要猜着编。
- 一次最多处理 **15 句**一个分片（模型一次吞太多会漏句）。分片也要一个一个交，最后合并成一个 JSON。
- 写完自己验一遍：**下标集合必须等于 `0..n-1`**，且 `n` = 输入 `cues` 的长度。

# KANA_TASK —— 假名词 / 外来语释义契约（派 subagent 干这个）

## 你要做什么

给 NHK やさしいことばニュース 里出现的**外来语、专有名词、汉字词**做两件事：

1. **注音**（汉字 → 假名），给 App 的逐字 ruby 注音查表用
2. **释义**（一句话中文），给生词面板用

## 输入

`work/out/<epid>_kana.json`（由 `scripts/build_site.py` 或派单脚本准备），形如：

```json
{
  "台风": 3,
  "宫崎县": 1,
  "气象厅": 2
}
```

（值 = 出现次数，次数少的优先处理）

## 输出

### ① 注音表（补进 `site/app/data/reading.js`）

`work/out/<epid>_reading.json`：

```json
{
  "宫崎县": "みやざきけん",
  "山梨县": "やまなしけん",
  "気象庁": "きしょうちょう"
}
```

🔴 **只给表里还没有的词**（已存在的不要覆盖，避免把对的改错）。
🔴 读音用**NHK 播报腔**的读法（`今日` = `きょう`、`留意` = `りゅうい`…），长词按词组读。
🔴 送假名（`の`/`に`/`で`…）**不要**进这张表（前端自己处理）。

### ② 释义

`work/out/<epid>_kana.json`（覆盖写）：

```json
{
  "台风": {"r": "たいふう", "zh": "台风（外来语，来自英语 typhoon）"},
  "气象厅": {"r": "きしょうちょう", "zh": "气象厅（日本的气象厅，负责天气预报和警报）"},
  "宫崎县": {"r": "みやざきけん", "zh": "宫崎县（日本的一个县，在九州南部）"}
}
```

- `r` = 读音（同上）
- `zh` = **一句话**中文释义；外来语可以补一句"来自英语/法语…"，帮助记忆

## 硬性纪律

- 🔴 **读音必须是你真的知道的**。不确定的**不要瞎写**——跳过它，并在文件末尾列一个 `{"_skip": ["词"]}`。
- 🔴 **不要给普通的日常汉字词做释义**（`今日`/`天気`/`電車` 这种学习者早就会的，别占位置）。
- 🔴 外来语要写清**语种来源**（用户是中文母语者，对来源敏感）。
- 🔴 每个词最多 40 字释义，别写小作文。

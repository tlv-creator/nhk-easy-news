# WO_TASK —— 本轮翻译工作单契约（派 subagent 干这个）

> 本轮要翻的是 **NHK やさしいことばニュース** 的**新的一期**（2026-11-04 ~ 11-16）。
> 每一期有两条轨：
> · **easy** = 易懂版正文（慢速音在念的）—— **两样都要**：整句中文 + 成分块中文
> · **web**  = 普通版（报纸原文）—— **只要整句中文**

---

## 输入

`work/wo/<epid>.json`，长这样：

```json
{
  "epid": "20261116de76490",
  "title": "火事で焼けた沖縄の首里城…",
  "tracks": {
    "easy": [
      {"i": 0,
       "ja": "沖縄県那覇市の首里城は、7年前の火事で焼けました。",
       "blocks": [{"text": "沖縄県那覇市の首里城", "role": "主语", "s": 0, "l": 9},
                  {"text": "は", "role": "语气", "s": 9, "l": 1}]}
    ],
    "web": [
      {"i": 0, "ja": "7年前の火災で焼失した首里城正殿…", "blocks": [...]}
    ]
  }
}
```

- `i` = 句子下标（从 0 开始，连续）
- `blocks[]` = 这一句被切成的**成分块**（角色见 `role`）——**顺序和数量都不许改**

---

## 输出（**四个文件，写在 /workspace/nhk/ 下**）

### ① 整句中文

`work/zh/<epid>_easy.json`（easy 轨）和 `work/zh/<epid>_web.json`（web 轨）：

```json
{
  "0": "冲绳县那霸市的首里城，在7年前的大火中烧毁了。",
  "1": "被称为正殿的建筑，用4年施工，恢复了原样。"
}
```

🔴 **键是句子的下标（字符串）**，值是这一句的中文。
🔴 **下标必须与输入的 `i` 一一对应**：不缺、不多、不改顺序。
🔴 **一个句子也不许漏**（漏了 ⇒ 整期不上线）。

### ② 成分块中文（**只做 easy 轨**）

`work/syn_out/<epid>_easy.json`：

```json
{
  "0": ["冲绳县那霸市的首里城", "（主题）", "在7年前的大火中烧毁了"]
}
```

🔴 **值的个数必须正好等于该句 `blocks[]` 的个数，顺序一致**。
🔴 每个字符串 = **那个块的中文意思**（贴着块的字面意思，不要泛泛而谈）。
🔴 块是词/短语级别的 ⇒ 中文也要短（几个字到十来个字），别写成整句。
🔴 **web 轨不做这个文件**（不要生成 `work/syn_out/<epid>_web.json`）。

## 翻译风格（照已发布数据）

1. **简体中文**、口语化，像老师讲给 N5 学习者听；**不要书面腔**
2. **数字两侧留空格**：`「第 277 期」`「1 番」`「800 人」`「33℃」
3. 专有名词/英文**保留原文**：`台风30号`、`NHK`、`PHP`、`ESG`
4. 语气词（えー、ねー）翻译成自然的中文语气即可
5. **web 轨是报纸原文**（书面语）——译文也要书面一点，但仍然用简体

## 硬性纪律

- 🔴 **不许自己编原文**。原文以输入为准（`ja` 字段）。
- 🔴 **不许把两句并成一句**「省事」——下标必须对得上。
- 🔴 遇到看不懂的句子，**照直翻**，并在最后的报告里列出那句，**不要猜着编**。
- 🔴 **一次最多处理 15 句一个分片**（一次吞太多会漏句）。分片要一个一个做完，最后合并成一个 JSON 文件。
- 🔴 写完**自己验一遍**：
  - `work/zh/<epid>_easy.json` 的键集合 == `0..n-1`，n = easy 轨句数
  - `work/zh/<epid>_web.json` 的键集合 == `0..m-1`，m = web 轨句数
  - `work/syn_out/<epid>_easy.json` 每个值的长度 == 对应句 `blocks[]` 的长度
- 🔴 **只写这两个/这三个文件**，不要动 `site/app/` 下的任何东西（那是主会话在管的）。

- 有没有看不懂的句子（列出下标 + 原文）

🔴 **`ver` 与 `apkVer` 是两个计数器，语义不同，别混**：
- `ver` = 站点内容版本（内容涨得比 APK 快）
- `apkVer` = 站上 APK 的真实 versionCode（App 判断「有没有新 APK」**只能用它**）
⇒ 用 `ver` 比 APK 的 APP_CODE ⇒ 判据恒真 ⇒ 用户被「發現新版本」死循环提示。

## 3. 数据模型（照线上产物反推，**唯一事实源 = 线上站**）

### 3.1 `site/app/data/episodes.js`
```js
window.__EPISODES__=[{ "id":"20261021de62763", "no":1,
  "title":"…", "easyTitle":"…", "date":"2026-10-21", "week":"", "time":"20:10",
  "duration":77.06,          // 慢速音时长（秒）
  "durFast":166.85,          // 原速音时长（秒）；没有原速音 = 0
  "subs":"subs/20261021de62763.js",
  "audio":"media/slow/20261021de62763.m4a",
  "audioFast":"media/fast/20261021de62763.m4a",
  "ver":["easy","web"] }]    // 该期有哪几版文本
```

### 3.2 `site/app/subs/<epid>.js`
```js
window.__SUBS__["<epid>"]={
  "easy":[ {s,e,ja,zh,t,c,g,y,yb}, … ],   // 慢速音 + 易懂版正文
  "web" :[ … ],                            // 普通版：报纸原文（阅读用）
  "sp"   :[ … ]                            // 普通版：电视播报稿（跟音用，s/e 是原速音毫秒）
}
```
每条 cue 的字段：
| 字段 | 含义 |
|---|---|
| `s`,`e` | 毫秒。`easy`/`sp` = 真实音轨时间轴；`web` = 原速音时长上的**按比例摊分**（阅读模式不高亮，容差大） |
| `ja` | 日文原句（**纯文本，不含注音括号**） |
| `zh` | 整句中文翻译 |
| `t` | 逐字切分 `[[起始字符, 长度, 片段], …]`（Sudachi 形态切分：`な/り/まし/た`） |
| `c` | 内容块 `[[起始字符, 长度, 片段], …]`（生词/词块） |
| `g` | 句型标签 `[[起始字符, 长度, patterns.js 里的 id], …]` |
| `y` | 整句结构 `[[起始字符, 长度, syntax.js 的角色 id], …]`（`SY.r`） |
| `yb` | 与 `y` 一一对应的中文（成分块中文） |

🔴 **前端靠字符位置在原句里定位**（可点、可注音）⇒ **每个片段必须逐字来自原句**，不能改写、不能脑补。

### 3.3 其余表
- `data/reading.js`：`{"今":"いま",…}`（汉字→假名，查表注音，**不内联 ruby**）
- `data/patterns.js`：`{"1":{"n":"～ます（丁寧・現在）","c":…,"m":…,"f":…,"k":468,"ex":[…]}}`（句型表 + 例句）
- `data/chains.js`：`{"te_miru":["…","…"]}`（形态链）
- `data/syntax.js`：`{"r":{角色id:{n,d}},"p":{词性id:词性}}`

## 5. 授权链（抓音声的四道坎）

慢速音/原速音都在 `media.vd.st.nhk`（Akamai）⇒ 没有 `hdnts` 一律 403。
链子（从共享仓库 `scripts/refetch_audio.py` 反推）：
```
auth.get_token()            → t["token"]      # news.web.nhk/tix/build_authorize（需 idp/redirect_uri…）
media_token(t["token"])      → hdnts          # 换取 HLS 授权串
m3u8 = https://media.vd.st.nhk/news/easy_audio/<base>/index.m3u8?hdnts=<hdnts>
下载：ffmpeg -headers "Referer: https://news.web.nhk/\r\nUser-Agent: Mozilla/5.0\r\n" -i <m3u8> -c copy -bsf:a aac_adtstoasc -f mp4 out.m4a
```
🔴 **下载完必须过体检**（`scripts/audio_health.py`）：削平 >5% / 超满刻度(4.0 口径) >0.05% / 时长对不上 ⇒ 硬失败重抓。
   （HLS 拼 TS 偶发坏帧 ⇒ 20261016de60356 实测过 +74.7dBFS 爆音。）

## 8. 已知限制 / 坑

- **普通版只有一部分期有原速音声**（44 期里 16 期）⇒ 其余期普通版是纯阅读对照。
  🔴 **绝不能拿慢速音凑**（`a = a.fast || a.slow` ⇒ 新闻稿配易懂版的词 ⇒ 声画全错）。
- 🔴 **原速音必须 id 精确匹配**：NHK 新闻页底部挂着**最新一期**的播放器，页面上第一条 m3u8 属于**别的新闻**。
  ⇒ 「找不到精确匹配就退回第一条」的兜底**已删除**，别加回去（27 期里 17 期抓错过）。
- 🔴 **普通版的「音」和「字」本来就不是同一份文本**：原速音=电视播报稿（口语），普通版正文=报纸原文（书面）
  ⇒ 字面不一样 ⇒ 拿报纸原文套播报音的时间轴会「跳句」⇒ 普通版必须存**两份文本**（`web` + `sp`）。
- 🔴 **普通版「音字同步」开关**（2026-10-24）：`S.settings.sp` 默认**开**；关掉 = 纯阅读（不高亮、不自动滚）。
  开关要**立即生效**并**记住**（localStorage）。跟易懂版共用同一套 `cueIndexAt`/`scrollCueTo`。
- **NHK 视频/图片有地域限制** ⇒ 本项目只做音声+文本，不做视频。
- 网页版「⬇ 下載」依赖 Service Worker（`sw.js`）⇒ 必须 https。
- **AI 讲解真接口**：`CFG.AI_ENDPOINT` 指向 CloudBase 中转，key 只在云端环境变量 ⇒ **绝不能写进前端**。
- 🔴 **AI 超时 ≥ 中转上游超时 + 余量**：中转 60 秒 ⇒ 前端 **75 秒**（别改回 45 秒）。
- 🔴 **AI 的两种模式必须共用同一份上下文**：`aiBuildBody()` → 请求体 → `aiBuildPrompt()` → 纯文本。
- 🔴 **`ja` 必须是纯文本**（不含括号注音），ruby 一律走 `data/reading.js` 查表。
- 🔴 **原生播放器只认绝对 URL**：`window.Android.playAudio()` 的地址要先 `new URL(u, location.href).href`。
- 🔴 **树状缩进判定必须「含树字符」**（│ ├ └），不能只看缩进。
- 🔴 **`pkill -f "xxx.py"` 会把自己的 bash 进程也匹配杀掉** ⇒ 写 `pkill -f "[x]xx.py"`。
- 🔴 **沙箱里 /tmp 会被回收** ⇒ 备份/中转一律放工作区。

## 2. 🔴 今天（10-27）新查清的关键事实

### 2.1 jiten.moe 免登录端点的真实能力

**能用（免登录）**
```
GET  /api/media-deck/{id}/detail            句数 / 时长 / YouTube id / 标题
GET  /api/media-deck/{id}/vocabulary?...     每集 unique 词（≈600-650）+ mainReading.text 内嵌逐字假名
GET  /api/media-deck/{id}/vocabulary-preview 前 N 高频词（带 readingFurigana + occurrences）
GET  /api/media-deck/{id}/stats|difficulty|coverage-curve   统计
POST /api/media-deck/{id}/download   body {"format":N,"downloadType":1,"order":1}
POST /api/vocabulary/{wordId}/{readingIndex}/example-sentences-by-difficulty/{mediaType}
      ?take=999&mediaTypes=11   body []  → 句子 + wordPosition + sourceDeck
```

**`download` 的 format 真实含义（踩过坑）**
| format | 内容 | 备注 |
|---|---|---|
| 1 | Anki .apkg | 词条 + **逐字注音** + 一个例句；SQLite `collection.anki21` |
| 2 | **CSV** | `Word,ReadingFurigana,ReadingKana,Occurences,ReadingFrequency,PitchPositions,Definitions,ExampleSentence,JmDictWordId` ← **最有价值** |
| 3 | Txt | **去重词表**（不是全文） |
| 4 | TxtRepeated | **按词分组**、每个词重复 N 次 → **不含原文顺序，不能重建全文** ⚠️ |
| 5 | Yomitan ZIP | 只有词频元数据，**无句子、无 ruby** |
| 6 | — | 400 |

**不能用（全部 401 / 空）** ← **这是本任务的最大瓶颈**
```
/api/media-deck/{id}/sentences · iplusone-sentences · learn · sentence-stats · sentence-summary
/api/media-deck/{id}/coverage-journey · view(204 空) · /api/vocabulary/{w}/{r}/readable-sentences
POST /api/srs/word-example-sentences（body 要 excludedDeckIds 等，无法限定到单个 deck）
```
⇒ **jiten 免登录拿不到「某一集的全部句子列表」**，只能拿到「每词一个例句」。

### 2.2 CSV 的 ExampleSentence 不能直接当本集句子
- Ep.665：637 词 → 309 个去重例句，但**归属率**（例句分词后落在本集词表的词占比）
  ≥0.6: 275 ／ ≥0.8: 153 ／ ≥0.9: 79（该集 sentenceCount=179）
- 例句里 `**word**` **只标了目标词**，不能当词边界用
- `sourceDeck.deckId` **不等于** BSJ 集的 deckId（探过：Ep.665 的例句没有一条 sourceDeck==144090）

### 2.3 外部源可达性（今天实测）

❌ anchor.fm（BSJ 的 RSS 域名）· patreon.com · youtube.com · web.archive.org · rss2json(Cloudflare)

### 2.4 已有但**没用上**的强源
- **2outube.com** `GET /api/transcript?v=<vid>` → 日文原轨 + 时间戳，**免登录**
  但免费额度**每天只给 1 个新视频**（探测 700 集后只有 Ep.3/5/653 在缓存）
- **youtubetranslate.net** `POST /api/subtitle {videoId,currentTime}` → 只有 Ep.653/664
- **iTunes lookup** `entity=podcastEpisode&limit=200` → **只有最新 200 集，无 offset**
- **jiten 注册**卡在 reCAPTCHA（`recaptchaResponse` + `model` 必填）
